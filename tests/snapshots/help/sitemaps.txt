
 Usage: gsc sitemaps [OPTIONS]

 Карты сайта ресурса: тип, ошибки, предупреждения, даты отправки.

 --json: {"ok": true, "site", "count", "sitemaps": [{path, type, errors, warnings,
 is_pending, is_sitemaps_index, last_submitted, last_downloaded, contents: [{type,
 submitted, indexed}]}]}; contents — сколько URL каждого типа (web, image, video) в карте.

 Example: gsc sitemaps -s sc-domain:example.com

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --site   -s      <str>  Ресурс Search Console: sc-domain:example.com или https://example.com/.   │
│                         По умолчанию — site из .gsc/config.toml проекта.                         │
│ --json                  Машиночитаемый вывод: JSON в stdout.                                     │
│ --quiet                 Не печатать ничего, кроме данных.                                        │
│ --help                  Show this message and exit.                                              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
