
 Usage: gsc status [OPTIONS]

 Показать проект: имя, путь, ресурс Search Console по умолчанию.

 Example: gsc status --json

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json             Машиночитаемый вывод: JSON в stdout.                                          │
│ --quiet            Не печатать ничего, кроме данных.                                             │
│ --verbose          Подробная диагностика в stderr.                                               │
│ --help             Show this message and exit.                                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
