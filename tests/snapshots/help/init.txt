
 Usage: gsc init [OPTIONS]

 Создать проект в папке: .gsc/config.toml с ресурсом по умолчанию (--site) и min_version.

 Example: gsc init --site sc-domain:example.com

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --name             <str>  Имя проекта (по умолчанию — имя папки).                                │
│ --site     -s      <str>  Ресурс Search Console по умолчанию для команд проекта (sc-domain:… или │
│                           https://…/).                                                           │
│ --force                   Перезаписать настройки уже созданного проекта.                         │
│ --json                    Машиночитаемый вывод: JSON в stdout.                                   │
│ --quiet                   Не печатать ничего, кроме данных.                                      │
│ --verbose                 Подробная диагностика в stderr.                                        │
│ --help                    Show this message and exit.                                            │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
