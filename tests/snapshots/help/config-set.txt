
 Usage: gsc config set [OPTIONS] {key} {value}

 Изменить одну настройку (не секрет — ключи только через auth login).

 Example: gsc config set site sc-domain:example.com

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    key        <str>  Ключ настройки через точку, например site или cli.min_version.            │
│                        [обязательный]                                                            │
│ *    value      <str>  Новое значение (строка). [обязательный]                                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Машиночитаемый вывод: JSON в stdout.                                            │
│ --quiet          Не печатать ничего, кроме данных.                                               │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
